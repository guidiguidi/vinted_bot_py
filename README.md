# Vinted Notifications Bot & AntiGravity Sniper

Telegram-бот для мониторинга новых товаров на Vinted в реальном времени с поддержкой фильтрации по странам, встроенного снайпера (автоматического бронирования), реферальной системы и крипто-платежей через CryptoBot.

---

## 🚀 Основные возможности

- 🔍 **Парсер Vinted**: отслеживание поисковых запросов пользователей с гибкой настройкой интервалов.
- 🎯 **AntiGravity Sniper**: сверхбыстрое автоматическое резервирование товаров при появлении.
- 🌐 **Продвинутая работа с прокси**:
  - Поддержка форматов `ip:port:user:pass`, `user:pass@ip:port`, `ip:port`, `http://...` и `socks5://`.
  - Добавление единичных прокси и списков через Telegram-админку, команду `/addproxy` или в коде через `proxies.add_proxies()`.
  - Загрузка прокси по ссылке (URL).
  - Параллельная валидация прокси.
  - Ротация User-Agent и интеграция со статистикой DataImpulse.
- 💳 **Коммерческий модуль**:
  - Подписочная модель с оплатой через CryptoBot (USDT).
  - Ключи активации доступа.
  - Реферальная система.
- ⚙️ **Админ-панель в Telegram**:
  - Управление списком прокси и скрейпером.
  - Настройка разрешенных стран (allowlist).
  - Рассылка сообщений пользователям и управление подписками.

## 📦 Установка и запуск

### 1. Клонирование и установка зависимостей
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd vinted
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка конфигурации
Скопируйте шаблон переменных окружения:
```bash
cp .env.example .env
```
Заполните параметры в `.env`:
- `TELEGRAM_TOKEN` — токен вашего Telegram-бота (от @BotFather).
- `BOT_USERNAME` — username бота.
- `CRYPTO_TOKEN` — токен CryptoBot (при использовании крипто-оплаты).
- `ADMIN_CONTACTS` — контакты администратора.

Синхронизируйте настройки с базой данных:
```bash
python3 sync_config.py
```

### 3. Назначение администратора
```bash
python3 make_me_admin.py
```

### 4. Запуск бота
```bash
python3 vinted_notifications.py
```

## 🌐 Управление прокси

### Добавление прокси через Telegram-бот:
1. В боте откройте **Админ панель** → **⚙️ Настройки бота** → **🌐 Прокси**.
2. Нажмите кнопку **➕ Добавить прокси** и отправьте прокси в чат.
3. Либо отправьте команду:
   ```text
   /addproxy ip:port:user:pass
   ```

### Добавление прокси через Python:
```python
from proxies import add_proxy, add_proxies, get_proxies_list

# Добавить один прокси
add_proxy("192.168.1.1:8080:user:pass")

# Добавить несколько прокси (дубликаты пропускаются)
added, total = add_proxies([
    "1.2.3.4:8080:user:pass",
    "http://user:pass@5.6.7.8:3128"
])
print(f"Добавлено: {added}, Всего в базе: {total}")
```
